# Abdul Ahad — Personal Portfolio

Recruiter-focused portfolio for GitHub Pages.

## Files
- `index.html` — portfolio website
- `resume.pdf` — place your latest resume here

## Publish on GitHub Pages

Repository:
`abdulahad79.github.io`

From this folder:

```bash
git init
git branch -M main
git remote add origin https://github.com/abdulahad79/abdulahad79.github.io.git
git add .
git commit -m "Create recruiter-focused portfolio"
git push -u origin main
```

If the remote already exists, skip `git remote add origin`.

Then in GitHub:
**Settings → Pages → Deploy from a branch → main → / (root) → Save**

Your site will be:
https://abdulahad79.github.io

## Before publishing
Put your latest resume PDF in this folder and name it exactly:
`resume.pdf`
